# 早高峰秒杀页面渲染优化方案

整体方案采用 **SSR + CDN + 资源预加载**，分别优化首屏内容生成、静态资源分发和关键资源加载，以降低首屏等待时间，并缓解高并发下的服务端压力。

## SSR

由服务器直接生成包含首屏内容的 HTML，浏览器收到响应后即可开始渲染，无需先等待客户端 JavaScript 执行，从而加快首屏内容展示。

## CDN

将静态资源分发至 CDN 节点，并通过缓存和预热提前准备热点资源。高峰期间，用户可从就近节点快速获取资源，减少源站带宽和并发压力，同时降低资源加载延迟。

## 资源预加载

根据资源的使用时机和优先级提前加载，缩短关键资源的等待时间，减少白屏和卡顿。

- `<link rel="preload">`：加载当前页面即将使用的关键资源，如首屏字体、关键 CSS 和首屏图片。
- `<link rel="modulepreload">`：提前加载 ES Module 及其依赖，减少模块解析和依赖获取的等待。
- `<link rel="prefetch">`：以较低优先级预取后续页面可能使用的资源，提升页面跳转体验。

预加载应聚焦关键资源，避免过度预取占用带宽，反而影响当前页面的加载速度。
